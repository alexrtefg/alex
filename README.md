# 💪 Дневник тренировок: Telegram-бот

Личный дневник тренировок в зале. Пишешь одной строкой `жим лежа 4х10х60`, бот записывает упражнение под сегодняшней датой, понимает опечатки («жиму леж» = Жим лёжа) и строит отчёты. Без искусственного интеллекта.

План проекта: [docs/decomposition-gym-diary-bot.md](docs/decomposition-gym-diary-bot.md)

## Что умеет (версия 1)
- Тренировки **А** (грудь, спина, руки) и **Б** (ноги). Бот сам предлагает следующую и показывает, что было в прошлый раз.
- Запись одной строкой: `жим лежа 4х10х60`, `жим лежа 60 10 10 8 8`, `подтягивания 3х8 +16`.
- Умный поиск названий с опечатками. Если бот не уверен, он предлагает варианты кнопками и запоминает твой выбор.
- **Пресс-трисет** одним словом `пресс`: 2 круга по 30 + 110 + 105 (или `пресс 2 30 110 100`).
- Отчёты: тренировка, неделя, месяц, год, отдельное упражнение (`прогресс жим`) с рекордами и расчётным 1ПМ.
- Калькулятор блинов: `блины 87,5` → «15 + 15 + 7,5 + 1,25 на сторону».
- Выгрузка в Excel (`/export`) и резервная копия базы (`/backup`).

Дальше по плану: графики и дашборды, рекомендации по правилам.

## Запуск на Windows (первый раз, ~10 минут)

### 1. Проверь Python
Нажми `Win + R`, введи `cmd`, нажми Enter. В чёрном окне введи:
```
py --version
```
Должно быть `Python 3.11.x`. Если пишет «не найдено», переустанови Python с [python.org](https://www.python.org/downloads/) и **поставь галочку «Add Python to PATH»**.

### 2. Скачай проект
1. Открой репозиторий на GitHub.
2. Слева вверху переключи ветку (кнопка с названием ветки) на `claude/stoic-brown-bp1jl5`.
3. Зелёная кнопка **Code → Download ZIP**.
4. Распакуй архив, например в `C:\gym-bot`.

### 3. Запусти
Дважды щёлкни файл **`start.bat`** в папке проекта.

При первом запуске он:
1. создаст окружение Python и установит библиотеки (1–2 минуты);
2. откроет Блокнот с файлом `.env`. Замени `вставь_сюда_токен` на свой токен от @BotFather, сохрани (`Ctrl+S`) и закрой Блокнот.

Если в окне появилась строка `Бот запущен`, всё работает. Открой своего бота в Telegram и нажми **Старт**.

> ⚠️ Окно `start.bat` закрывать нельзя: пока оно открыто, бот работает. Остановить бота можно сочетанием `Ctrl+C` или закрытием окна.

### 4. Сделай бота только своим (рекомендуется)
Бот на `/start` пишет «Твой Telegram ID: 123456789». Открой файл `.env` в Блокноте и впиши этот номер в строку `OWNER_ID=123456789`. Перезапусти `start.bat`. Теперь чужие люди, даже если найдут бота, получат молчание.

## Где хранятся данные
- Все тренировки лежат в файле **`gym.db`** в папке проекта. **Не удаляй его.**
- Раз в неделю-две отправляй боту `/backup`: он пришлёт копию базы прямо в Telegram.
- При обновлении бота (новый ZIP) копируй новые файлы поверх старых. `gym.db` и `.env` в архиве нет, поэтому они не затрутся.

## Как добавить или переименовать упражнение
Открой `exercises.py` в Блокноте (или в VS Code). Каждое упражнение записано одной строкой:
```python
Ex("bench", "Жим лёжа", "chest", ("жим", "жим штанги лежа")),
```
- `"bench"`: внутренний код (латиница, уже записанные коды не меняй);
- `"Жим лёжа"`: название в отчётах;
- `"chest"`: группа мышц (`chest`, `back`, `biceps`, `triceps`, `shoulders`, `legs`, `abs`);
- в скобках перечислены твои другие названия этого упражнения.

Там же лежат шаблоны тренировок А/Б, состав пресс-трисета, вес грифов и количество блинов.
